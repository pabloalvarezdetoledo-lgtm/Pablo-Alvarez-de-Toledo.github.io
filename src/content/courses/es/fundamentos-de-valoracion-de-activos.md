## Sobre este curso

**Esta es una estructura de curso de demostración.** Existe para mostrar cómo se organiza la sección de Clases del sitio —módulos, lecciones ordenadas, duración, bibliografía y ejercicios— y para dejar claro cómo será un curso terminado. Todavía no existe ninguna grabación en vídeo ni apuntes escritos: esta página no afirma que exista actualmente ningún contenido de lección.

Cuando se graben las lecciones, cada una enlazará a una incrustación de YouTube con privacidad mejorada, apuntes escritos, diapositivas descargables, una breve bibliografía y, cuando corresponda, ejercicios, código y datos.
